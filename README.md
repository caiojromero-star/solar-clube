# Solar Clube — site

Site estático do Solar Clube (Mogi Mirim/SP), publicado pelo GitHub Pages.

- `index.html` — página inicial
- `cadastro/` — cadastro de clubistas e alunos (grava na tabela `cadastros` do Supabase do Solar, projeto `solar-clube`; o público só consegue inserir, não lê nada)
- `estilo.css` — identidade visual do Solar (mesma do kit de placas)

A chave que aparece no código é a **chave pública** (publishable) do Supabase, feita pra ficar no navegador. Nenhuma chave secreta fica neste repositório.
